# Histórico não exibe linhas novas

- **Pedido:** `1d9239e4-af1f-4a90-b148-feb5f5962dbf` da Equipe Pregão (errado, Estratégias), aprovado por um administrador.
- **Trecho da tela:** "nenhuma linha nova na tela"
- **O que acontece:** O botão 'Histórico' na tela de Estratégias não altera o estado da página, mantendo o usuário na mesma URL e sem exibir novas informações. O trader espera visualizar um log de execuções passadas ou uma tabela de dados históricos para análise, mas a interface permanece estática após o clique.
- **O que ajustar (sugestão de quem testou):** O botão deve ser funcional e direcionar para uma nova visualização ou expandir uma seção que contenha o histórico de trades (log de compras e vendas). A ação deve mudar o estado da página para exibir esses dados em vez de apenas recarregar a URL atual.
- **Corrigido em:** 27/10/2026, no ramo `pregao/1d9239e4-10271607`, pelo ThinkBitcoin-Back-Python-Agents-Oficina (gemma4:12b).

## Causa e correção

O botão de "Histórico" na tela de Estratégias (Zoo) estava desativado via propriedade `disabled` no componente de abas, o que impedia a mudança de estado e a navegação para a visualização de dados históricos. A correção remove essa propriedade, permitindo que o clique na aba altere a URL e exiba o conteúdo correspondente. O teste foi atualizado para verificar que a aba agora está habilitada.
