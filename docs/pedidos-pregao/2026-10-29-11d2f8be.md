# Filtro de tempo sem resposta visual

- **Pedido:** `11d2f8be-611c-4f3f-9800-786fc730f5fc` da Equipe Pregão (errado, Treinamento IA), aprovado por um administrador.
- **Trecho da tela:** "1 h"
- **O que acontece:** Na tela de Treinamento IA, o botão "1 h" não apresenta nenhuma mudança visual ou resposta ao ser clicado, mantendo a lista de "Últimos episódios" completa. Para um trader, isso é um erro de usabilidade, pois a expectativa é que o seletor filtre os dados instantaneamente para mostrar apenas os resultados da última hora. A falta de resposta impede a análise rápida de dados em tempo real.
- **O que ajustar (sugestão de quem testou):** Implementar a funcionalidade de filtro no botão "1 h" para que ele atualize a lista de "Últimos episódios" exibindo apenas os registros da última hora. A mudança deve ser refletida visualmente de forma imediata após o clique do usuário.
- **Corrigido em:** 29/10/2026, no ramo `pregao/11d2f8be-10291028`, pelo ThinkBitcoin-Back-Python-Agents-Oficina (gemma4:12b).

## Causa e correção

O problema ocorre porque o componente `UltimosEpisodios` exibe a lista completa de episódios retornada pelo hook `useTreinamentoEpisodios` (que mantém um cache dos grupos de 4 horas buscados), sem filtrar esses itens de acordo com a janela de tempo selecionada pelo usuário. Ao selecionar "1 h", o hook busca os dados daquela janela, mas os dados das janelas anteriores permanecem no estado `itens`. A correção consiste em passar a `janela` para o componente `UltimosEpisodios` e aplicar um filtro usando `useMemo` para exibir apenas os registros cujo `dataHora` esteja dentro do intervalo `[janela.inicio, janela.fim)`. O teste confirma que, ao selecionar uma janela de 1 hora, episódios fora desse intervalo são removidos da lista.
