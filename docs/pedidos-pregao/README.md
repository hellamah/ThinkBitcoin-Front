# Correções dos pedidos da Equipe Pregão

Um arquivo por correção que o ThinkBitcoin-Back-Python-Agents-Front fez a partir de um
pedido da Equipe Pregão aprovado por um administrador: o pedido, a causa e a correção nas
palavras do modelo, os arquivos mudados e o teste que prova a correção. O arquivo entra no
mesmo commit da correção, e o PR passa pela revisão do dono como qualquer outro.
