# Botão de Atualizar apenas exibe status de cache

- **Pedido:** `adb29e5d-37c3-4d65-8f05-a1b091dbc6a6` da Equipe Pregão (errado, Geopolítica), aprovado por um administrador.
- **Trecho da tela:** "⚡ Dados em cache (atualizado há menos de 5 min)"
- **O que acontece:** O botão 'Atualizar Dados' na tela de Geopolítica exibe apenas a mensagem '⚡ Dados em cache (atualizado há menos de 5 min)' sem alterar os valores exibidos na tela. O campo 'Interesse Atual' permanece estático em '100/100' mesmo após o clique, impedindo que o trader confirme se os dados refletem a situação atual do mercado. Isso transforma um botão de ação em um simples indicador de status, prejudicando a tomada de decisão rápida.
- **O que ajustar (sugestão de quem testou):** O botão 'Atualizar Dados' deve disparar uma requisição real ao servidor e atualizar o valor numérico do campo 'Interesse Atual' imediatamente. O sistema deve refletir a mudança nos dados assim que a atualização for concluída.
- **Corrigido em:** 27/10/2026, no ramo `pregao/adb29e5d-10271508`, pelo ThinkBitcoin-Back-Python-Agents-Oficina (gemma4:12b).

## Causa e correção

O problema ocorre porque o `useEffect` que observa o `refreshTrigger` (vindo do `DashboardContext`) chama a função `carregarHeatmap()` sem argumentos. Como a função `carregarHeatmap` tem o parâmetro `forceRefresh` como `false` por padrão, o sistema continua buscando os dados do cache mesmo quando o usuário clica em "Atualizar Dados". Ao passar `true` para a função dentro do `useEffect`, forçamos a `apiRequest` a ignorar o cache e atualizar os dados da tela.
